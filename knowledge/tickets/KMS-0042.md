# Semantic search over the knowledge base

## Problem

Lorekeeper users can only find documents by exact keyword. When a researcher
looks for "prior work on onboarding", a document titled "New-hire ramp-up notes"
never surfaces — same concept, different words. People re-investigate questions
that were already answered because the answer is unfindable. This is the single
most common complaint in user interviews (7 of 9 sessions).

## Why it matters

The whole value proposition of a knowledge base is *recall* — surfacing what the
team already knows. Keyword-only search breaks that promise the moment vocabulary
drifts, which it always does across teams and time.

## Scope

**Must have**
- Semantic (embedding-based) search over document title + body.
- Results ranked by cosine similarity, blended with a keyword signal.
- Single search bar in the top nav; results show title, doc type, one-line excerpt.
- Minimum 3 characters before querying; 300ms debounce.
- Results capped at 20, returned within 500ms on a 10,000-document corpus.

**Nice to have**
- Highlight the matched passage inside the excerpt.
- "More like this" from a document detail page.

**Out of scope**
- Cross-workspace / cross-tenant search.
- Natural-language question answering (that is KMS-0070, a separate ticket).
- Re-ranking with an LLM (evaluate after v1 ships).

## Acceptance criteria

- Given the query "prior work on onboarding", the document "New-hire ramp-up notes"
  appears in the top 5 results.
- Search returns within 500ms (p95) on the 10k-document benchmark corpus.
- Deleting a document removes it from results within one index-refresh cycle.
- Keyword-exact matches still rank at or above semantic-only matches.

## Open questions (resolved during research)

- Which embedding model? → resolved in the ADR (local `bge-small`, see linked ADR).
- Rebuild vs. incremental index? → incremental; see the plan.

## Definition of done

Plan implemented, benchmark in `knowledge/artifacts/` meets the 500ms bar,
relevance eval in `knowledge/validation/` passes, review verdict is APPROVED.
